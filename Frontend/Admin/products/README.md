# DT Brand's Admin — Module 2: Products & Catalogue Management

Complete production-quality desktop UI for DT Brand's & Jai Hanuman Tex.

## Structure
- `index.php`: Master Products List (9 summary cards, debounce search, multi-filter bar, bulk actions, data table, pagination).
- `add.php`: Multi-section Add Product Studio (Basic Info, Media Dropzone, Multi-tier Pricing Calculator, Variant Matrix, SEO Preview, Inventory & Shipping).
- `edit.php`: Product Editor with live sync.
- `view.php`: Executive Product Inspection, Sales Analytics KPIs (7D/30D/3M/1Y), Wishlist & Conversion, Audit Timeline.
- `categories/`: Categories Taxonomy Studio.
- `subcategories/`: Subcategories Hierarchy.
- `brands/`: Brands Roster.
- `attributes/`: Variant Attributes & Values Matrix.
- `media/`: Media Library & High-Res Gallery.
- `reviews/`: Product Reviews Moderation.
- `featured/`, `best-sellers/`, `new-arrivals/`: Curated Collection Managers.
- `imports/`: 7-Step Product Import Wizard.
- `exports/`: Export Studio (CSV / Excel / PDF).
- `components/`: 14 Reusable PHP components.
- `assets/css/`: Modular stylesheets.
- `assets/js/`: Modular JavaScript controllers.
