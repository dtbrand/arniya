# Security Policy — DT Brand's & Jai Hanuman Tex

## 1. Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## 2. Reporting a Vulnerability
We take the security of DT Brand's and our wholesale, reseller, and customer data seriously.
If you discover a security vulnerability, please report it privately:

- **Email:** `security@jaihanumantex.in`
- **Response SLA:** Within 24 hours acknowledging receipt, fix within 72 hours for critical items.

## 3. Strict Security Rules
- **Zero Secrets in Code:** Never commit credentials, passwords, private keys, or API tokens.
- **SQL Injection Prevention:** Parameter binding across all dynamic queries.
- **XSS & CSRF Mitigation:** HTML entity encoding and strict token verification.
- **Least Privilege:** Minimum required permissions on all GitHub tokens and server processes.
