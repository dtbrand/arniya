# 👑 DT Brand's & Jai Hanuman Tex — Module 3: Catalogue Management

## 📌 Module Architecture Overview

Module 3 is the master taxonomy and merchandising suite for DT Brand's & Jai Hanuman Tex. It is completely isolated from product creation (Module 2) while providing full taxonomy controls:

- **Hierarchy & Taxonomy**: Multi-level category tree with real-time product counts, parent-child connectors, expand/collapse toggles, and drag-and-drop position sorting.
- **Categories & Subcategories**: Dedicated CRUD management with luxury DT Brand styling, automatic slug generators, image and hero banner uploaders, and visibility configuration.
- **Curated Collections**: Seasonal and promotional groupings (Festive Lines, Wedding Collections, Trending Assortments) with interactive dual-panel product assignment.
- **Featured Catalogue Manager**: 1-click star featured toggling for homepage gold ribbons and spotlight badges.
- **Visual Navigation Builder**: Header menu tree constructor with drag indentation and live 4-column mega menu desktop layout previews.
- **Visual Merchandising**: Product position pinning, top-ranking badges, visibility hiding, and custom sorting rules.
- **Storefront Display Settings**: High-density grid columns (2 to 6 columns), image ratios, pagination sizes, and badge visibility toggles.
- **SEO & Google Rich Snippets**: SERP Google preview boxes, title tag and meta description character meters, canonical links, and OpenGraph tags.
