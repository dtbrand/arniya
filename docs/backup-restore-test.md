# Backup Restore Testing & Disaster Verification Standard

## 1. Objective

Verify that automated snapshots generated by the backup subsystem are restorable without corruption, data loss, or syntax errors.

## 2. Test Procedure

1. Run `php scripts/restore-test.php` weekly.
2. In staging environment, import snapshot into temporary test schema `arniya_restore_test`.
3. Check table count (28 tables), row counts, and primary key sequences.
4. Execute smoke tests against the restored staging database.
