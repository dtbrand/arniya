# Search Bar Left Icon Rule

## Rule

- **ALWAYS** place the search magnifying glass icon on the **LEFT side** of every search input field across all components and pages (Wholesaler, Shop, Single Product, Reports, Orders, Header, Modals, etc.).
- Ensure proper left padding (`padding-left: ~40px-44px`) so text and placeholder content never collide with the search icon.
- Provide an optional 1-tap clear button (`✕`) on the right side when the user types text.
