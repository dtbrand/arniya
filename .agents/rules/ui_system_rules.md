# 🎨 DT Brand's Master UI Design System & Styling Mandate

Based on [AI/UI_SYSTEM.md](file:///c:/Users/sai/Desktop/WhatsApp%20CRM/AI/UI_SYSTEM.md):

## 1. Signature Brand Color Palette
- **Heritage Master Gold**: #8A681F (Buttons, key accents, numbers)
- **Radiant Accent Gold**: #D4AF37 / #C5A859 (Glows, active highlights, borders)
- **Obsidian Dark Hero**: #181512 / #2A241E (Dark headers, hero cards)
- **Pale Gold Tint**: #FAF5E8 (Card highlights, secondary pills)
- **Emerald Success**: #15803D & #DCFCE7 (WhatsApp buttons, In-Stock)
- **Deep Obsidian Text**: #111827 / #1F2937 (High-contrast typography)

## 2. Universal Button & Icon Mandate
- **100% Styled Buttons**: Every button MUST have a background gradient, border, and hover state. Never use plain browser buttons.
- **100% Real Vector SVGs**: Zero emojis in core buttons, table headers, or navigation.
- **Indian Rupee (₹) Mandate**: ZERO dollar signs ($). Always use the SVG Rupee icon or ₹ symbol.

## 3. High-Density Compact Wholesale Ergonomics
- Admin inputs must be compact (height: 30px - 32px, padding: 3px 8px, ont-size: 11.5px - 12px).
- Section cards: compact headers (padding: 6px 10px) and bodies (padding: 8px 12px).
- Fluid auto-sizing for Desktop, Tablet, and Mobile across all KPI ribbons, toolbars, tables, and modals.
